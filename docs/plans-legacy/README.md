được chuyển vào đây ngày 2026-08-13 để `README.md` / `DEPLOYMENT.md` /

(ví dụ `xem PLAN_REAL_ORDER_PLACEMENT.md` trong `trading/real_orders.py:14`).

sửa hàng loạt: đổi 14 file production chỉ để cập nhật đường dẫn trong comment
là thay đổi rủi ro hơn lợi.
